# 博客配图

仓库内的可复用技能源文件；已在公共记忆文章中完成一次三图生成与页面验收。不假定它已被任何工具自动加载，也不把一次实践当成跨环境验证。

## 权威与范围

先读仓库根目录 [AGENTS.md](../../../AGENTS.md) 的配图规范，再打开文中指定的站内成品。交接材料提供构图候选，不能覆盖本站已确认的视觉约定。本文只补充 Prompt 留档、模型调用和来源记录，不复制整套站点规范。

文章专用 Prompt 放在 `docs/design/<post-slug>-image-prompts.md`。需要公共记忆主题实例时，读 [hindsight 配图 Prompt](../../design/hindsight-shared-memory-image-prompts.md)。技能中不固化某篇文章的张数或节点数量。

## 最短工作流

1. 从成稿选出需要图才能减轻理解负担的关系。封面只表达核心命题；正文图解释关系。已有表格足够时不再画同维度图。
2. 先留档公共风格块、逐图构图和全部图内文字。每张实际请求的完整 Prompt = 公共风格块 + 对应构图块；调用时关闭额外 Prompt 自动增补，或把实际增补内容一并保存。
3. 优先使用环境提供的 `imagegen` 能力和 `gpt-image-2`。内置入口不可用时说明缺口；经明确指定的网关可用 API 路径。网关端点与凭据由运行环境提供，不存入本仓；缺少信息时只询问端点及凭据存储标识，不要求发送明文 key。不自行切换模型或用 SVG 冒充生图。
4. 原图先核对文字、箭头与裁切。图中文字错误就修 Prompt 重生成，不靠局部覆盖文字伪装成功；同一图连续两次不合格，先减少节点或缩短标签，再决定是否继续调用。已有合格图不覆盖，直到新图验收通过。
5. 按 AGENTS.md 导出最终 WebP，逐张打开并放回文章验收。源图本就是 16:9 时直接等比缩放；其他比例先检查安全边距，裁切会丢信息就重新生成，不强行拉伸。检查 360px 和桌面、Light/Dark、放大入口，再运行现有图片门禁与 `git diff --check`。

## 公开留档

正文、Prompt、技能、文件名、图片文字及附带元数据都按公开仓库标准检查：不含内部仓名、公司标识、私人机器名、内网地址、私有链接、个人绝对路径、凭据或真实 Keychain 条目名。公开产品名、公开一手来源和仓库相对资源路径可以保留。不要把交接包、原始对话或网关响应原样复制进仓库。

每张图记录：实际模型、最终完整 Prompt、请求尺寸、生成次数、最终路径、尺寸、字节数和验收状态。未调用就写“未生成 / 0 次”，参数未被服务验证就写“计划参数”；不能把现有图片或失败后残留文件算成本次结果。只记录安全的错误摘要，不保留可能含凭据的请求头或完整响应。

导出过程中的 PNG、临时批处理输入和缓存不提交。确定性 SVG 只用于 AGENTS.md 允许的精确文字或几何场景，且须事先明确说明；若本次明确要求全部模型生图，则不走该替代路径。

## 边界示例

- “给这篇博客配封面并保留 Prompt”：使用本技能。
- “修改文章页布局”：走仓库 CSS 约定，不使用本技能。
- “图中必须严格按坐标表达比例”：先按仓库规则判断确定性绘图是否更合适，不因本技能偏好而强行生图。
