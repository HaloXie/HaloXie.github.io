# 教学节点参考

用于角色图的动作、神态与简短对话设计。六张图的画风及参考用途已于 2026 年 11 月 12 日获明昊确认；不表示每个道具、体型细节或技术隐喻均成为不可改的模板。角色身份以 [角色设定](characters.md) 为准。

| 节点与参考图 | 动作与交流职责 | 短话术示例 |
| --- | --- | --- |
| [提问](../assets/nodes/node-question.webp) | 白猫指出差异，水獭认真思考；问题指向具体对象 | 为什么这里不一样？ |
| [探讨](../assets/nodes/node-discussion.webp) | 水獭摆出两种方案，白猫参与思考，水豚学长追问依据 | 你们分别是怎么想的？ |
| [详细解析](../assets/nodes/node-explanation.webp) | 水豚指向关键条件，学员跟随因果关系；不同时解释所有模块 | 先看这一处，它决定了后面。 |
| [反驳／反例](../assets/nodes/node-counterexample.webp) | 白猫提出不同条件，其他人检查证据；不怒视或指责 | 换成这种情况，还成立吗？ |
| [发现错误](../assets/nodes/node-error.webp) | 水獭指出结果与预期的差异，白猫协助核对；不羞辱角色 | 我漏掉了这个条件。 |
| [验证正确](../assets/nodes/node-correct.webp) | 学员展示可对照的结果，学长给予反馈；认可不能替代证据 | 这次和预期一致。 |

按文章选择节点，不强制按六步顺序编排。允许角色互换提问、纠错与验证动作：白猫不固定犯错，水獭不固定正确，水豚保持引导职责而非唯一答案来源。话术根据具体知识改写，不每篇重复原句。

## 模型输入与校验

- 先按角色设定选择当前形象板，再传本次需要的一张节点图。明确形象板管身份与体态，节点图只管构图、互动和神态。不能只传旧三角色图，使水豚回到中年导师形象。
- 六图统一为奶油底、黑色手绘线、明快色块和自然角色互动。角色占比、动作与道具按主题调整；不要把参考板或六图拼贴整体送入模型要求照抄。
- “反驳”图额外出现方孔，更像不同形状与条件的比较，不能直接当作严谨的“方块无法通过圆孔”论证；实际文章需重新核对几何和逻辑。
- “发现错误”和“验证正确”各自的卡片与积木顺序可用于展示比较，但两图的预期顺序不相同。若用于连续教程，必须先统一目标顺序，不能直接前后连用声称完成同一任务。
- “解析”中的闸门只是示例，不能外推为任意技术系统的机制。部分图中水豚仍偏圆厚，新图以当前学长形象板约束体态，不将该偏差升级为人设。

六图均由实际 `gpt-image-2` 编辑请求生成，各一次成功，输入为原三角色图、新版水豚学长板和新版白猫小师妹板。输出 1536×864 PNG，最终等比缩成 1200×675 WebP、quality 85，单图低于 65KB。已打开检查；未接入文章或验证页面 Light/Dark。完整公开输入见 [生成记录](../../../design/blog-teaching-nodes-prompts.md)。
