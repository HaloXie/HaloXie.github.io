# 模型用角色动作参考库

用于生成/编辑角色插图时选取动作参考，不是直接贴到文章里的切图，也不是透明精灵素材。角色身份、性格和教学职责仍以 [角色设定](characters.md) 为准。

## 使用方法

1. 先按 [当前角色设定](characters.md) 打开水豚学长、白猫小师妹的修订板；水獭沿用原板。旧三角色图只提供画风和人物关联，不能覆盖新版面部、体态。
2. 下表按本次场景挑一张单格图，实际打开后作为第二张图片传给支持多图输入的生成/编辑模型。明确第一张管身份与相对体型、第二张只管动作和所需神态；仅在文字里写文件名不等于模型看到了图。
3. 单图输入时优先传主参考并文字描述动作，不为了动作丢掉身份约束。不一次塞入全部动作板，避免模型画出重复角色或接触表。
4. 成图对照主参考核验脸型与身份，再核对场景动作。保留自然神态变化，不要求所有表情相同；若眼型、口鼻、耳位或身体比例明显漂移，局部编辑或重生，不能通过拉伸或锐化假装修复。

## 动作索引

各板按左上、右上、左下、右下排列；单格按完整角色边界裁出并居中放入统一画布，不是放大所得。下表水獭保留使用；水豚与白猫旧板/单格仅保留作历史探索，不再作为模型默认输入。当前水豚使用 [学长修订板](../assets/actions/senior-current.webp)，白猫使用 [小师妹修订板](../assets/actions/cat-current.webp)。修订板按左上至右下分别为：邀请一起看、示范、自然倾听、比较；提问、生活举例、比较差异、动手验证。新版尚未裁出单格，不能以旧单格冒充新版。

## 分辨率与限制

- 三张模型输出源图实际均为 3072×1728，按角色边界裁出后原像素居中放入 12 张 1536×864 单格画布；仓内参考以 WebP quality 95 保存，未插值放大。画布尺寸不等于角色占满画布，不承诺任意放大仍清晰。
- 此处是明昊要求保留清晰度的模型输入资产，不是文章发布图，不加入历史图片尺寸豁免。文章最终配图仍遵循 AGENTS.md 的 1200×675、WebP 和体积门禁。预览缩图不能替代高清参考传入模型。
- 水豚板下排转向使小包出现在画面另一侧，不能当成随意镜像配饰的许可；按主参考和真实转身关系核对肩带。
- 白猫的站立/俯身及水豚转向带来脸部、体态差异；候选动作不应固化这些差异为新的身份特征。先前主参考未展示的脚部和站姿属本次模型推演，尚未由明昊定稿。
- 浅奶油背景不透明，不拿它们直接叠加到网页。若需要不同机位或超出参考的表情，基于主参考再生成，不强行变形复用。
- 单格补边与原图纸底有轻微色差，属于参考画布而非最终画面边框；提示模型只参考角色，不照搬矩形底色。输出前仍检查最终背景统一性。
