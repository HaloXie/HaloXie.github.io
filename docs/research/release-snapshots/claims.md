# 教学论断核验

| 论断 | 出处 | 核验方式 | 结论 |
| --- | --- | --- | --- |
| 指针表示期望，加载失败仍用上一份成功配置 | 本站发布与回滚文章的设计契约 | 独立试读 + 模型反例测试 + 浏览器两阶段观察 | 通过，仅指本文设计，不代表所有系统自动具备 |
| r1 恢复的是 A/B 各半，不能达到停用 B 的目标 | 本例快照定义 | 独立重算；浏览器恢复 r1 显示 B50% 且未达目标 | 通过 |
| 恢复目标改变，适当候选也会改变 | r0/r1/r2 假设记录 | 同一 r1 分别对照目标 B0% 与 B50% | 通过 |
| 相同比例不代表本次加载成功 | 同版本加载失败反例 | 独立核验发现原措辞问题，主审采纳并修复；测试增加保留状态断言 | 通过 |
| hash 只核对内容，不能证明正确或获批 | 原文章定义 | 正文与反馈核对；成功选项明确以获批内容为前提 | 通过 |
| 回滚配置不能撤销已经产生的数据或结果 | 快照只保存配置的范围 | 独立领域逻辑核验 | 通过 |
| 比例是配置权重，不是小样本计数 | 演示模型范围 | 图注与候选说明常显/折叠对照 | 通过 |

可见文字抽取脚本运行得到 70 条及 2 处静态数字；脚本不完整解析 mjs，两位审阅者另读 app.mjs/model.mjs，未以抽取数量冒充覆盖率。

独立 agent 模拟试读非真人验证。采纳：前提常显、独立入口明确模拟、同版本失败措辞、恢复关插画错位、重复复述调整。两位均能复述对象关系、加载失败及恢复目标差异。
