# 指针变了，新请求会用哪份配置？

- 学完能预测：给定恢复目标、候选快照、加载结果，判断新请求的 A/B 分流及是否达到目标。
- 现象：指针更新与实例成功加载分步展示；加载失败时实例和流量保留旧配置。读者作为第四位参与者选择并预测，中性反馈针对结果追问；角色只在文章的连续漫画内出现。
- 主变量：三个剧情节点分别为发布 r2、停用 B、恢复实验；候选版本和加载成功/失败可选择。
- 联动：候选快照 → 期望指针 → 实例加载 → A/B 比例。图形比例、文字、解释反馈从同一纯函数产生。
- 默认参数：发布关当前 r1，目标 B 全量，候选 r2，加载失败；恢复关当前 r2，目标停用 B，候选 r1；迁移关当前 r0，目标恢复实验，候选 r1。假设所有候选均已完整验证、获批且适用于本题环境。
- 默认可见：预测前结果 0 项；揭晓后默认发布关 B 为 50%，达到目标阈值为 100%，相差 50 个百分点。以上是设计预期，须用测试和浏览器验证。
- 先预测题：选项：A 全量 / A、B 各一半 / B 全量；选择版本、加载条件、理由与预测后锁定，先显示指针更新，再揭晓实际加载与预测对比。
- 叙述分支：按实际 loaded 和 desired 是否一致、实际 B 比例是否等于目标，分别解释未加载、目标不匹配、目标达成；理由选“最近”时追问旧版本内容，选“指针”时追问实例证据。
- 公式或模型：model.mjs 的 evaluate 为页面和测试共用纯函数。loaded = 加载成功 ? desired : previous；B = snapshots[loaded].b；goalMet = B === targetB。比例是配置权重，不是小样本请求计数。来源为本文设计契约，非线上模拟器。

## 范围、风险与回退

按已批准的交互方向做一个独立 lab 和三个文章内入口；不改生产全局 CSS、文章身份或英文稿。依赖现有主题桥和已确认角色图片，不新增库。观察：预测锁定、指针/实例分离、失败保留、目标差异、键盘及窄屏可用。JS 不可用时继续读正文；回退为移除三个 iframe 和新增 lab，不涉及数据迁移。不上线，不连接生产。

## 验收

模型反例测试、每关分支试读、桌面/窄屏明暗、重置与禁用脚本、文章门禁。豆包审读此前网关拒绝，预览不等于发布定稿。
