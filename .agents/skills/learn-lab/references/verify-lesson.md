# 核验一节课

**适用**：课做完、交学习者前；或学习者质疑课中某条内容。

**不适用**：做课/精修课（见 `build-lesson.md`）；评审与教学无关的普通网页。

## 谁来核

核验者不能是做课的 agent，最好换一个模型家族，比如一个做课、另一个核。实测：做课 agent 自检每次都过，错误全靠独立核验查出，见下方回归案例。

## 步骤

1. 跑 `node --experimental-strip-types '<SKILL_DIR>/scripts/extract-visible-text.ts' <课目录>`，抽出用户可见文字，每条标文件+行号，另附「HTML 写死的数值」表。覆盖范围和不覆盖的情况写在脚本头部注释里；全英文课加 `--all`。如果改过这个脚本，先跑 `node --experimental-strip-types --test '<SKILL_DIR>/scripts/extract-visible-text.test.ts'`，全部通过后再信它的输出。
   - 为何先抽：让核验者读截图会让上下文溢出（实测 2 次零产出）；让做课者自己列 `claims.md`，列出来的是功能清单（「有旋钮」），而不是教学论断（「光圈不弯折光线」）。
2. 逐条判是否教学论断。每条论断用三法之一核验：
   - **独立计算**：不抄页面代码，从公式重推，另写脚本。
   - **一手来源**：附链接+一句摘要。
   - **领域逻辑**：写清推理。

   结论仅三种：通过 / 错误（写正确说法）/ 未验证（写原因）。
3. 查以下 gate（非文字论断，抽取脚本抓不到）：
   - **同源**：拖控件后数字卡、叙述、画面同步变；HTML 无写死数值（抽取清单第二表）。叙述分支条件看计算结果，非仅输入：凡按 `degree >= 8` 类输入阈值切叙述的，核对分支说法与当时算出数值是否一致。
   - **默认可见**：默认参数打开，肉眼即见标题所述现象，按页面显示精度量。spec 实测值要复算。
   - **先预测可交互**：学习者能选、选后锁定、运行后揭晓，揭晓处并列预测与实际数值。仅印题目不算。
   - **画面不说谎**：画面几何关系也是论断。如光线弯折位置，查每段斜率，不只核文字。
   - **无源数**：凑出的系数/阈值，要么标来源，要么改有名常量并注明典型值。
4. **判定核验意见**：核验意见也可能误报，主 agent 逐条判误报/属实/待验证，属实才改。

## 回归案例（真实发生过，核验时逐条比对同类问题）

| 课 | 错误 | 做课者自检为什么没发现 | 哪道 gate 抓住的 |
| --- | --- | --- | --- |
| 梯度下降 | 说明写「两个局部极小值加一个全局最低点」，函数实际仅 2 个极小值 | 自检只核梯度公式 | 独立计算：网格搜极小值 |
| 梯度下降 | 默认起点直接滚进全局最低点，演示不出标题说的「卡住」 | 未查默认参数 | 默认可见 |
| 景深 | 默认 f/1.4，清晰带在 0–6m 线性横轴上仅 2.7px 宽，看不出 | 数值全对 | 默认可见 |
| 景深 | 模糊半径乘无来源 `0.55` 感知系数 | 当成视觉调参 | 无源数 |
| 相机 v1 | 快门数字卡显 1/500，滑杆标签写死 1/250 | 两处单看都「合理」 | 同源 |
| 相机 v1 | 用 1/500 作闪光同步阈值；典型值 1/160–1/250，且因机型而异 | 未查资料 | 一手来源 |
| 相机 v2 | 光线在光圈、快门平面也有折角，会让人以为光圈能弯折光线 | 功能清单只写「有光路」 | 画面不说谎：查每段斜率 |
| 相机 v2 | 50mm 定焦说明写「变焦环改变焦距」 | 文案与常量分开写 | 独立核对：说明文字对照 FOCAL_LENGTH 常量 |
| 相机 v2 | 待机写「快门关闭」；无反取景时机械快门是开的 | 按单反直觉写 | 一手来源（Kasson；Canon Europe） |
| 景深（误报） | 核验者要求模糊圆「再除以放大倍率」；实际上公式得出的已经是传感器上的尺寸 | — | 判定核验意见：判误报 |
| 过拟合（Codex 做） | 默认次数 9 显示 训练 0.001 / 测试 0.003，看似都近 0，看不出过拟合；11–12 次才明显（0.000 / 0.338） | spec 写「两项 loss 同屏可见」，属定性描述 | 默认可见：按显示精度复算 1–12 次 |
| 过拟合（Codex 做） | 叙述在 `d >= 8` 写「暴露泛化变差」，但 8 次恰是测试 loss 最低点 | 叙述按输入写，未对照算出数值 | 同源：叙述分支对照计算结果 |
| 过拟合（Codex 做） | 「先预测」仅一段静态文字，无选项无揭晓 | 做课者报告未提 | 先预测可交互 |
| 过拟合（Codex 第二版） | 测试点取无噪声真实趋势，训练点带噪声→次数 1–7 时测试 MSE 始终低于训练 MSE，易误导为「测试误差通常比训练低」 | 合成数据此副作用不在 spec | 画面不说谎：除主现象，还看数据带出的其他读法 |
| 过拟合（Codex 第二版，signal） | 预测题问「测试误差一定也下降吗？」，「一定」暗示答案 | — | 尚未归到 gate；再出现一次再定规则 |
| 相机 v3 | 预设「全清」标题写「f/16 前后都清楚」；实际对焦 1.5m 时清晰范围仅 1.17–2.08m | 预设标题凭直觉写，未用景深函数算 | 独立计算（Codex 核验） |
| 相机 v3 | 照片冲洗时用的是冲洗那一刻的 ISO，照片说明写的却是按快门时的 ISO | 存了快门参数，没存增益 | 同源：拍照任务须冻结全部状态 |
| 相机 v3 | 「先预测」整步丢失 | 需求另手写，非从 spec 派生 | 先预测可交互；根因为执行保护：只派 spec |
| 相机 v3（误报） | 核验者认为「镜筒说明提对焦环，但模型未实现对焦环」 | — | 判误报：讲的是真实镜头结构，本课未声称可转对焦环 |

## 输出

更新 `claims.md` 结论列。报告只写：错误（按严重度排序：严重度+问题+正确说法）、未验证项、查了哪些地方。无错误也须写清查过哪些地方。
