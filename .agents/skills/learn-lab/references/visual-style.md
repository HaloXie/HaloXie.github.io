# 视觉规格（第二档 3D 课）

**适用**：第二档 3D 实体物件课。动手做课前先读这一篇，它是「一层好看到什么程度」的唯一口径。
**不适用**：第一档单文件课；抽象概念课（不需房间、台面、3D 操作件）。

源头：相机课 v3，目前唯一达交付线版本。下列每条从它量出，非审美建议。

**动手前先看两张参考帧**（本 skill `assets/ref/`，用 Read 打开）：

- `assets/ref/camera-v3-overview.jpg` —— 整页版式：标题、左数据面板、右控制面板、中间主体、底部照片条。
- `assets/ref/camera-v3-exploded.jpg` —— 拆解视图：零件摊开、常驻胶囊标签、台面 3D 操作件。

照着这两张的密度和布局做。做完的课和它们并排看，差距写下来再改。

## 色与材质

页面单一暗色底，颜色全取自这组变量：

```
背景 #0f1628    面板玻璃 rgba(14,20,34,.62) + blur(16px)
主强调 青 #3fe0ff    次强调 橙 #ff8a2a
正确 绿 #7dffa8    警示 黄 #ffd24a    错误 红 #ff6b6b
正文 #eef2f8    弱化 #93a1b5    分隔线 rgba(255,255,255,.09)
```

- 数字一律等宽（`SF Mono`），正文 `SF Pro Display` / `PingFang SC`。
- 主体只用**一个主色 + 一个辅色**，零件倒角。只有正在起作用的零件发光，其余不发。
- 环境贴图须压暗（`envIntensity ≈ 0.35`）。相机课 v1 直贴白房间 `RoomEnvironment`，金属反射成灰白，像塑料。

## 版面

三栏固定，中间留给现象：

```
左上 标题     小字序号 + 一行大标题 + 一段说明（宽 272px，不给结论）
左中 数据面板  数字卡 + 因果链叙述 + 一到两张 SVG 小图（曝光图、景深尺）
右下 控制面板  分段按钮 / 滑杆 / 主操作按钮（宽 272px，≤ 300px）
底部 托盘      结果缩略图条（照片条），可留空
```

间距、圆角、字号在 `assets/kit/kit.css`，直接用，勿另起。

## 主体构图

- 主体占画面 **55–65%**。用 `views.js` 自动构图算，不手调相机。
- 面板用 `data-dock="left|right|top|bottom"` 声明占位，`freeRect()` 把主体挪到空白区中心，不被面板压、不被边缘裁。
- 场景须有地面、墙面、背景展品、植物，主体不能孤立在黑底上。
- 光源固定四个：半球底光 + 暖主光（投影）+ 冷补光 + 背后暖轮廓光。

## 操作件要长在场景里

旋钮、滑轨、仪表做成 3D 物体，台面上可拖，转动有挡位段落感（`controls3d.js` 的 `knob` / `gauge`）。右下分段按钮只放「切换类」选项，**主变量必须能在 3D 里直接操作**。

## 标签

胶囊标签加一条竖向引线锚在 3D 点上，**常驻显示**，不是点击后才出现。颜色跟对象的语义走（青 = 正在讲的那个，橙 = 对比对象）。

## 手感

- 状态变化全缓动，无硬切。
- 切机位相机运镜到预设，不瞬移。
- 场景常驻微动（风扇转、浮尘飘、灯带呼吸）。
- 悬停有反馈。

## 迭代方法

截图 → 与参考帧并排 → 写最大 3 差距 → 改。最多 3 轮。相机课三轮实际差距，可直接当检查项：

1. 布景空、道具稀疏；
2. 机位切掉控件半截；
3. 主体太小，认不出；
4. 结果（现象产物）需操作才出，静态截图看不到；
5. 金属反射白房间，像塑料。

## 已知陷阱

**`MeshBasicMaterial` 不支持 `.emissive`**：给 `MeshBasicMaterial` 赋 `.emissive`，three.js `refreshUniformsCommon` 每帧报 `Cannot read properties of undefined (reading 'value')`，整场景全黑。发光条、UI 元素用 `MeshBasicMaterial`，颜色走 `glow()` 或顶点色；`.emissive` 只用于 `MeshStandardMaterial` / `MeshPhysicalMaterial`。可先 `if ('emissive' in material) material.emissive.setHex(...)` 保护，但最简：按材质类型选颜色路径，不混用。

## 复用

`assets/kit/` 即相机课那套，随 skill 走，不依赖外部目录。接法：

1. `createStage({ container, bench })` → 房间、灯、台面、相机、后处理；台面 `y = 0`。
2. 物体加进 `stage.scene`；每帧逻辑写 `stage.onFrame`；副渲染裹 `stage.renderExtra`。
3. 机位用 `stage.views.define` / `stage.views.go`。
4. `</script>` 里 importmap 指 three 0.160.0（jsdelivr）。

`kit/` 不许 import `lab/`。新课若改 kit 本身，记下改动 —— 说明 kit 边界划错。

## 效果分三类

| 类别 | 例子 | 规则 |
| --- | --- | --- |
| 承载现象 | 景深、运动模糊、曝光增益 | 须与数字卡出自同一个模型，核验脚本能独立复算 |
| 只管手感 | 倒角、PCFSoft 阴影、GTAO（静止才开）、常驻微动、按钮回弹 | 可省；不许与承载现象效果矛盾 |
| 示意 | 噪点 | 页面标明示意 |
