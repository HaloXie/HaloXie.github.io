# 做一节交互课

**适用**：已定形式为 2D 交互、动画或 3D，写课规格并做课，或精修已有课。

**不适用**：文字+静态图课、检索游戏（直接做）；核验课（见 `verify-lesson.md`）。

## 课的规格模板（spec.md）

```markdown
# <问题式标题，例如：光圈开大，背景为什么会糊？>
- 学完能预测：<1 件事>
- 现象：<学习者眼前发生的是什么，例如：背景灯泡从小点变成大光斑>
- 主变量：<一个>；次变量：<至多两个，默认锁住>
- 联动：<改主变量后同时变化的每一处，例如：叶片、光锥、景深板、取景画面、测光表、图表上的点、叙述>
- 默认参数：<取值>
- 默认可见：<可测量> = <实测值>（阈值 <值>），由 <哪段计算或脚本> 得出。只写「同屏可见」「明显」这类定性描述不算。
  例：「测试 loss / 训练 loss = 2.3（阈值 ≥ 3，且显示精度下两个数可分辨）→ 不达标，改默认次数或加噪声」。
- 先预测题：<题干>；选项：<3 个>；学习者选定后锁住，运行后在揭晓处并列写出「你的预测」和「实际数值」
- 叙述分支：每个分支的条件写成计算结果（例：`testLoss > 2 × minTestLoss`），不写成输入阈值（例：`degree >= 8`）
- 公式或模型：<写出来，并注明来源>；页面和核验脚本共用同一份纯函数
```

抽象概念的课，现象就是一个算出来的量在屏幕上变化：改一个变量（层数、温度、键长），另一个量跟着变。例：

```markdown
# 温度调高，为什么模型说的话越来越随机？
- 学完能预测：同一句提示、同一批权重，温度从 0.2 调到 1.5 时，输出的分布会变成什么样
- 现象：柱状图上每个候选词的概率柱此消彼长；采样点在高概率柱之间跳动
- 主变量：温度
- 联动：概率柱高度、熵的数值、实时采样出的 token、右侧概率表
- 默认可见：温度 0.2 时 top-1 概率 = 0.91（阈值 ≥ 0.8，显示两位小数）；温度 1.5 时熵 = 2.7（阈值 ≥ 2.0）
- 先预测题：温度调到 1.5 后，最高概率那一列会怎样？选项：升高 / 基本不变 / 降低
```

除了「现象」和「联动」，抽象概念的课不需要另外一套规则；这个案例本身还没有实测过，第一次做时把意外记下来。

## 版式

- 左上：问题式标题，一行白、一行强调色；≤3 个关键数字；一段叙述写成因果链。例：「f/1.8 → 孔 ⌀27.8mm → 进光 +2 挡 → 景深 9cm → 背景灯泡变成大光斑」。
- 中间：现象本身。主体占画面 55–65%，不被面板挡、不被边缘裁。可用 `camera.setViewOffset` 把主体移到面板间空白处。
- 右上：预设和视图切换，面板宽 ≤ 300px。主要操作件做进场景，如旋钮、滑轨、仪表。
- 数值、画面、叙述皆从同一 state 派生。HTML 里不写死任何数值，初始化时统一渲染一次。

## 分档

| 档 | 做法 | 实测成本（2026-09-29，样本 4 课） |
| --- | --- | --- |
| 第一档 | 中阶模型，单文件，一次成型 | 约 5 分钟，20–30 次工具调用 |
| 第二档 | 高阶模型精修，截图对比，≤3 轮迭代 | 约 50 分钟，约 100 万 token，75 次工具调用 |
| 第二档 + 建套件 | 第二档基础上抽出 `kit/`，按物理计算取景 | 约 60 分钟，约 160 万 token，113 次工具调用 |

第二档比第一档贵 1–2 个数量级。仅反复使用或领域核心的课进第二档。

第二档活儿（美术规格、效果搭配、共用套件接法、迭代方式）见 `case-camera-lab.md`。规则来自实体物件课实测，抽象概念课勿整套照搬，先看该篇「可以推广的部分」。

## 执行保护（派给子 agent 做课时，写进它的 prompt）

- 派给子 agent 的输入只有两样：已过 `check-spec` 的 `spec.md` + 本文件。不要另外手写一份需求清单。实测：相机课 v3 的需求是另写的，「先预测」在转写时漏掉了；而且那一版没有 spec.md，`check-spec` 根本没机会拦。
- 无头环境渲染不畅（帧率近 0）时，「默认可见」改用计算验收：用页面自身的光学/数学函数，算出默认参数下的可见量（光斑像素直径、两个 loss 的比值等），和 spec 里写的阈值比较。

- 在课目录里建 `PROGRESS.md`，写清目标和清单，每完成一步追加一行。实测：连续 3 个子 agent 在上下文压缩后忘了任务，交出零产出，或反问「你要我做什么」。
- 截图先缩到约 800 宽再看（macOS 用 `sips -Z 800`），每轮最多看 2 张。运行时无截图能力则跳过截图迭代，只做数值和文字核验，报告写明「未做视觉核对」。
- 浏览器会话可能被别的任务占，截图用独立实例，勿共用会话。
- 已有大文件局部编辑，勿整体覆写。改前备份上一版，便于回滚和并排对比。

## 为什么这样做（证据，冷路径）

标 `未核` 者仅来自一次调研，未逐条回一手源核对；足以支撑此处做法（做法本身皆保守），但勿拿这些数字说服别人。

- 「现象优先」实测来源：相机课先后两版，第一版只写形容词，第二版写五项美术规格，两版均被评「只是一个 3D 模型」。主题改为「按下快门，看照片怎么被做出来」后才解决。

- 动画 vs 静态图：总体 d≈0.37；装饰性动画效应近 0；仅内容本身变化时动画占优。来源：Höffler & Leutner 2007，元分析。`未核`
- 内容相关美术：对记忆、理解、迁移 d≈0.32–0.39，对内在动机 d≈0.26。来源：Brom 等 2018，元分析，33 样本；2021 复现 g≈0.27–0.35。已核
- 诱惑性细节（有趣但与内容无关）损害学习。来源：Sundararajan & Adesope 2020，元分析。`未核`
- 先预测、观察、再解释（POE）：g≈0.98。来源：2024 元分析，35 项研究。`未核`
- 检索练习 g≈0.5–0.6，间隔练习 g≈0.74–1.01，测的是长期保持。依据：Karpicke & Roediger 经典实验及多个元分析。`未核`
- 交互模拟：引导过重致学生停止探索（PhET 访谈研究，非 RCT）。故用一道「先预测」题引导，不写分步操作说明。`未核`
