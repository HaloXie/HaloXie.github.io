改动一个 token，缓存停在哪里？

从左到右沿用同一段前缀。改变一张卡片的开头，校验头就停在它前面；后面的文字即使没变，也要重新计算。

选择一段，改动它的首个 token：

命中 2,048 token · 重算 2,048 token · 相对输入成本 55%

这台机器假设了什么

每个段末的前缀都已经缓存、仍然有效，本次也能查询这些边界。卡片只是教学分段，不代表厂商真实 block 大小或断点规则。一次只修改所选段的首个 token，输入总长度不变。

相对成本只比较本次输入的「缓存读取 + 普通重算」，以完全未命中的输入成本为 100%。读取倍率取 0.1，对应 Anthropic Claude Sonnet 4.6 的缓存读取价 / 普通输入价（查证：2026-10-12）。不含首次缓存写入、写入溢价及输出费用，不是完整请求账单。

来源：确定性 SVG（anatomy skill）。所有 token 与成本读数由同一个模型函数生成。
